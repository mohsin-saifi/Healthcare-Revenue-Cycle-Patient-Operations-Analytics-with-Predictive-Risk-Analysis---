# Healthcare Revenue Cycle & Claim Denial Analytics

## Project Overview
An end-to-end healthcare analytics project focused on
revenue cycle performance, insurance claim denials,
financial insights, and denial risk prediction.

## Objectives
- Analyze healthcare claims and billing performance.
- Identify major claim denial reasons.
- Monitor outstanding payments and collection rates.
- Compare insurance providers and hospital departments.
- Build a machine learning model to predict claim denial risk.

## Dataset
- 10,000 synthetic healthcare records
- 30 original columns
- Claim status: Paid or Denied
- Includes billing, insurance, patient,
  department, and payment-related attributes.

## Tools & Technologies
- SQL
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- Machine Learning (Scikit-learn)
- Power BI
- Git and GitHub

## Project Workflow
1. Data understanding and cleaning
2. SQL-based business analysis
3. Exploratory Data Analysis (EDA)
4. Statistical analysis
5. Claim denial prediction
6. Power BI dashboard development
7. Business insights and recommendations

## Machine Learning
Classification algorithms will be evaluated
using a train-test split and appropriate metrics,
including precision, recall, F1-score, and ROC-AUC.

## Disclaimer
This project uses synthetic data for educational
and portfolio purposes. It does not contain
real patient records.
